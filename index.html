Pemahaman Bermakna

Mengapa Ini Penting?

  • Banyak masalah berisi hubungan antarbenda atau tempat.
  • Diagram membantu melihat hubungan yang sulit dijelaskan.
  • Graf untuk hubungan bebas yang saling terhubung.
  • Tree untuk hubungan bertingkat dari satu akar.
  • Model yang baik tidak harus rumit, yang penting membantu.
  • Perubahan satu aturan dapat mengubah strategi kita.

Kode Sederhana

Membaca Tetangga pada Graf

# 1. Tentukan simpul (objek) simpul = ["Kelas", "Koridor", "Tangga", "Lab", "Perpus"] # 2. Tentukan sisi (hubungan) sisi = [("Kelas","Koridor"), ("Koridor","Tangga"), ("Tangga","Lab"), ("Koridor","Perpus")] # 3. Fungsi mencari tetangga sebuah titik def tetangga(t): hasil = [] for a, b in sisi: if a == t: hasil.append(b) if b == t: hasil.append(a) return hasil print(tetangga("Koridor")) # ['Kelas','Tangga','Perpus']

Model yang sama dapat dipakai untuk mencari jalur alternatif saat satu sisi ditutup.

Peringatan

Kesalahan yang Sering Terjadi

❌ Sering Salah

• Memasukkan objek yang tidak relevan.
• Tidak memberi label pada simpul.
• Menggambar hubungan yang tidak ada.
• Menganggap semua cabang adalah tree.
• Memberi strategi tanpa bukti diagram.

✅ Sebaiknya

• Hanya pakai objek penting.
• Beri nama setiap simpul.
• Sesuaikan dengan aturan kasus.
• Periksa akar dan arah hubungan.
• Tunjukkan bagian diagram pendukungnya.

Analogi

Peta Jalan vs Folder Komputer

Bayangkan peta jalan — kamu bisa berputar arah dan kembali ke titik awal. Itulah graf.

Bayangkan folder komputer — kamu masuk makin dalam, tidak bisa kembali lewat jalur lain. Itulah tree.

# Graf: boleh ada siklus A — B — C |_______| # Tree: tidak ada siklus, satu akar Akar / \ Anak A Anak B / Daun

Rangkuman

Poin Penting Hari Ini

  • Graf memodelkan hubungan bebas yang saling terhubung.
  • Tree memodelkan hubungan bertingkat dari satu akar.
  • Simpul, sisi, dan bobot adalah bahan dasar model.
  • Diagram adalah alat berpikir, bukan sekadar gambar.
  • Model yang baik membantu memilih strategi tepat.
  • Jika aturan berubah, periksa kembali model kita.
